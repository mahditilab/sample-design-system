# Prototypes

Page designs from Claude chat live here, one file per page: `home.html`, `blog.html`, `post.html` and so on.
They belong in your design-system repository. Claude Code builds the website pages from them.

- `home.html`: the home page. Split hero with portrait, latest posts as link cards with images, about, how I work, closing call to action.
- `blog.html`: blog index, a simple list of posts (date, title, one-line summary).
- `post.html`: a single post, reading column with a sticky "On this page" contents on the side. On phones the contents sit above the text.

Names, dates and text in these prototypes are placeholders.
